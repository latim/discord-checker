<h1 align="center">Discord Username Checker</h1>

<p align="center">
  Generates usernames based on a pattern and checks which ones are available on Discord, using proxies.
</p>

<img src="https://i.pinimg.com/originals/14/aa/d6/14aad66b004dd19cf52b7b82f3ef64fe.gif" alt="demonstração" width="600">

## How use

1. Install [Python](https://www.python.org/downloads/) and check **Add Python to PATH**.
2. Double-click `instalar.bat`.
3. Open `proxies.txt` and paste your proxies, one per line.

Available names are saved to `found.txt`.


## Proxies

One per line in `proxies.txt`, in the formats `ip:port`, `ip:port:user:password`, or `user:password@ip:port`. For SOCKS, use `socks5://ip:port`.


## Disclaimer

This tool uses an unofficial Discord endpoint and is not affiliated with Discord. Excessive use may result in your proxies being blocked. Use at your own risk.
